### Phase 3: SCAMPER Refinement → Service Packages

## Final Service Package Architecture

### Package 0: AI Pulse (FREE)
- Weekly newsletter + community Zalo group + monthly webinar + self-audit checklists
- Purpose: audience building, lead nurture, authority
- KPI: 5,000 subscribers Year 1

### Package 1: AI Second Opinion ($0-300)
- 90 phút session: Report Card (A-F grading × 6 dimensions) + Competitive Benchmark + Fix 1 Thing live + Phác đồ AI 5 trang
- Free via referral voucher from existing clients, $300 walk-in
- KPI: 15-20/tháng, 50%+ convert

### Package 2: AI Chef's Table ($500/person)
- 3h monthly event, 5-8 people: trend update + live-build on real business + Q&A + early bird offer
- Biến thể: Client Chef's Table, Private Chef ($2-3K), Virtual ($200)
- Revenue: $30-48K/năm + conversion pipeline

### Package 3: BếpOS / ShopOS — Vertical AI Operating System
- **Lite $500/m:** Dashboard + 3 workflows + Onboarding Quest + Zalo support
- **Pro $1,500/m:** + Advanced AI (forecast, CRM, multi-channel) + bi-weekly calls + Boss Battles + add-ons
- **Elite $3,000/m:** + Dedicated concierge + weekly calls + custom integrations + VIP Data Room + 4h SLA

### Package 4: AI Black Card ($5,000/m, invitation only, max 20)
- Unlimited implementations + bespoke solutions + monthly dinner with founder + beta access + personal brand package + annual VIP retreat

### Package 5: AI Bootcamp ($3,000-8,000/team)
- 3-day intensive or 8-week program: AI literacy → hands-on build → deploy + measure
- Cohort version: 10 owners × $5K = $50K/cohort
- 80%+ convert to OS subscription

### Package 6: AI Alliance (Partnership Program)
- Referral Partners (accountants, associations): free, $200-500/referral
- Certified Partners (agencies, freelancers): $2K training + $500/m license, 70/30 revenue share
- Platform Partners (KiotViet, MISA): negotiate, distribution to 150K+ merchants

### XP Loyalty Engine (across all packages)
- Actions earn XP: onboarding (100), renewal (100), referral (200), testimonial (150), Boss Battle (75)
- Tiers: Bronze → Silver (500 XP) → Gold (1,500 XP) → Platinum (3,000 XP)
- Perks escalate: discounts (10-20%), strategy calls, VIP Data Room, retreat invite, concierge
