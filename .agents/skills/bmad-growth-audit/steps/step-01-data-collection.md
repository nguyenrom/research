# Step 01 — Data Collection

**Phase:** 1
**Lead agent:** bmad-growth-analyst

## Steps

1. **Define Audit Scope** (bmad-growth-analyst) — Set the time period (30/60/90 days), channels to analyze, key questions, success metrics, and comparison benchmarks. → output: `audit-scope.md`
2. **Website Analytics** (bmad-growth-analyst) — Collect traffic-source breakdown, user behavior, conversion funnels, landing-page performance, and technical performance. → output: `website-analytics.md`
3. **Content Performance** (bmad-content-architect) — Analyze top and underperforming content, content by type, engagement patterns, and content ROI. → output: `content-performance.md`
4. **SEO Performance** (bmad-seo-strategist) — Analyze organic traffic trends, keyword rankings, backlink profile, technical SEO health, and competitor SEO comparison. → output: `seo-performance.md`
5. **Social Media Performance** (bmad-social-media-strategist) — Analyze follower growth by platform, engagement rates, top posts, best posting times, and audience demographics. → output: `social-performance.md`
6. **Email Performance** (bmad-growth-analyst) — Analyze list growth, open rates, click rates, conversion rates, and unsubscribe trends. → output: `email-performance.md`

## References for this step

- `references/tracking-plan-template.md` — Use this whenever the audit reveals event-tracking gaps. Object-Action naming, GA4 setup, identity stitching all live there.

## Exit criteria

- Audit scope agreed in writing.
- All 6 channel-level outputs produced; none skipped without explicit user opt-out.
- No data integrity blocker (e.g., GA4 sampling making metrics unreliable).
