# Marketing Psychology Models — Catalog and Ethics

> Reference loaded by Phase 1 step 3 of `bmad-copy-conversion-sprint`. Use only models that match the user's actual buyer context. Apply the ethical-persuasion guardrail at the bottom before shipping.

## Bucket 1 — Foundational Thinking

| Model | When it helps | Marketing application |
|---|---|---|
| First Principles | Cluttered category, copycat positioning | Strip claim to atomic truth: "What is the buyer's exact moment of struggle?" |
| Jobs To Be Done | Persona-driven copy feels generic | Reframe around the job, not the demographic ("hired to do X") |
| Inversion | Stuck on what works | Ask "what would make conversion impossible?" then avoid those |
| Pareto (80/20) | Bloated feature messaging | Find the 20% of features driving 80% of decisions |
| Theory of Constraints | Funnel has many leaks | Find THE binding constraint and fix it before others |
| Barbell Strategy | Conservative or aggressive content debate | Run both: 80% safe + 20% asymmetric upside |

## Bucket 2 — Buyer Psychology

| Model | When it helps | Marketing application |
|---|---|---|
| Endowment Effect | Trial → paid conversion | Let users own data/work in trial, hard to give up |
| IKEA Effect | Customers value what they build | Onboarding that asks them to set up their workspace |
| Goal-Gradient | Mid-funnel drop-off | Show progress bar; near-completion accelerates action |
| Peak-End Rule | Onboarding fatigue | Ensure peak moment + ending are excellent (the rest blurs) |
| Zeigarnik Effect | Email open rates | Cliffhangers: open loops in subject line resolved in body |
| Pratfall Effect | Stiff brand voice | Admit a small flaw — increases trust |
| Curse of Knowledge | Founder writes their own copy | Test copy with people unfamiliar with the product |

## Bucket 3 — Persuasion (Cialdini + extras)

| Model | When it helps | Marketing application |
|---|---|---|
| Reciprocity | Cold audience | Free tool / lead magnet / actually useful free thing |
| Commitment & Consistency | Multi-step funnel | Get small yes early, larger asks later |
| Social Proof | New brand, trust gap | Customer count, named logos, recent activity feeds |
| Authority | Technical buyer | Founders' pedigree, named experts, audited certifications |
| Liking | Cold outreach | Shared school/employer/interest in opener |
| Scarcity | Decision delay | Real, honest scarcity (not fake countdowns) |
| Unity | Identity-driven product | "Founders building for founders" framing |
| Foot-in-Door | Reluctant buyer | Free → paid → upsell path |
| Door-in-Face | Premium positioning | Open with high anchor, settle on real ask |
| Decoy | Pricing page | Add a deliberately worse option to make middle tier obvious |
| Anchoring | Pricing presentation | Lead with highest tier or annual price |
| Framing | Same data, different reaction | "90% activation" beats "10% drop-off" |

## Bucket 4 — Pricing Psychology

| Model | When it helps | Marketing application |
|---|---|---|
| Charm Pricing | Consumer SaaS | $19 vs $20 — works on price-sensitive buyers |
| Rule of 100 | Discount framing | <$100 use percentages, ≥$100 use dollar amounts |
| Decoy Pricing | Three-tier page | Make middle tier obviously the best deal |
| Mental Accounting | Annual billing | Frame "$X/mo billed annually" vs "$Y/yr" — same number, different feeling |
| Pain of Paying | Subscription friction | Hide the recurring nature in onboarding, surface in retention |

## Ethical Persuasion Guardrail

**Rule**: Never use a psychological lever to push the buyer toward a decision that is not in their interest.

Specifically prohibited:
- Fake scarcity timers / fabricated stock counts
- Hidden recurring charges, surprise renewals, hard-to-cancel flows
- Confirm-shaming UI ("No thanks, I don't want to grow my business")
- Decoy pricing that traps users in the wrong tier
- Authority claims without credentials
- Social proof from invented or unverified customers

**Test each lever**: "If the buyer knew exactly what we are doing here and why, would they still consent?" If no, change the lever.
