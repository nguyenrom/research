# Step 03 — Launch Day (J-Day)

**Phase:** 3
**Lead agent:** bmad-launch-coordinator
**Timebox:** J-Day 06:00 → 22:00

## Steps

1. **Morning Activation** (bmad-launch-coordinator) — *J-Day 06:00* — Verify all systems, activate landing page, send first email blast, publish blog post, final social check. → output: `morning-activation.md`
2. **Social Media Blitz** (bmad-social-media-strategist) — *J-Day* — Execute launch announcement posts, threads/carousels, community engagement, influencer coordination, real-time monitoring. → output: `social-execution.md`
3. **Launch Monitoring** (bmad-growth-analyst) — *J-Day, ongoing* — Real-time tracking of traffic, conversions, social engagement, error detection, and hourly updates. → output: `launch-monitoring.md`
4. **Community Engagement** (bmad-social-media-strategist) — *J-Day, ongoing* — Active engagement: respond to comments, answer questions, share user reactions, handle issues. → output: `engagement-log.md`
5. **End of Day Review** (bmad-launch-coordinator) — *J-Day 22:00* — Day-1 assessment: metrics summary, wins and challenges, next-day priorities, team appreciation. → output: `day1-review.md`

## Real-time decision rules

- **Conversion rate < 50% of baseline by 12:00**: pause paid amplification, investigate funnel, escalate to owner.
- **Site error rate > 0.5%**: rollback non-critical changes immediately, full rollback if > 2%.
- **Social sentiment > 30% negative**: convene crisis comms within the hour.
- **Viral spike (10x baseline traffic)**: scale infra, prepare moderation, draft "thank you" follow-up.

## Exit criteria

- All 5 outputs saved.
- Day-1 assessment shows go-forward (not crisis mode).
- Next-day priorities documented for Step 04.
