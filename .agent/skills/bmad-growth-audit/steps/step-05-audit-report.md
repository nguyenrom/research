# Step 05 — Audit Report

**Phase:** 5
**Lead agent:** bmad-growth-analyst

## Steps

1. **Executive Summary** (bmad-growth-analyst) — Capture 3–5 key findings, critical issues, top opportunities, recommended priorities, and expected outcomes. → output: `executive-summary.md`
2. **Full Audit Report** (bmad-growth-analyst) — Compile the executive summary, current-state analysis, SWOT, channel deep-dives, recommendations, action plan, and appendices. → output: `growth-audit-report.md`
3. **Report Presentation** (bmad-growth-analyst) — Walk stakeholders through findings, discuss recommendations, answer questions, agree on priorities, and define next steps. → output: `audit-presentation.md`

## Output quality bar

- Executive summary fits on 1 page.
- Full report has cover, exec summary, methodology, findings, SWOT, recommendations, KPI framework, appendices.
- Presentation surfaces 3-5 most-actionable findings, not all 20+. Cognitive load matters.

## Exit criteria

- 3 outputs produced.
- Executive summary signed off by user.
- Next-workflow recommendation chosen and surfaced in `### Completion`.
